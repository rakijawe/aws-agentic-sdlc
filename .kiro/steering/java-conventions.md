
# Java Coding Conventions

## Naming
Classes: PascalCase  
Methods/Variables: camelCase  
Constants: UPPER_CASE

## Structure
controller/
service/
repository/
model/

## Logging
Use SLF4J, no System.out

## Testing
Minimum 70% coverage

## REST Standards
- Proper HTTP codes
- Versioned APIs

## Git
- Feature branches
- PR reviews
